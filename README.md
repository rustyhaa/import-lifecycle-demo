# 수입상품 생애 추적 데모

수입상품이 물류센터에 들어온 뒤 매장으로 나가 팔리기까지를 주 단위로 따라가는 화면 데모입니다.

- 실무자 화면(첫 화면): `index.html` (가상 품의 8건의 목록, 생애 차트, 비교, 경보)
- 일반 사용자 화면: `user.html` (사례 4개: 계속 입고 · 빨리 소진 · 매장 체류 · 센터 정체)

화면의 상품·수치는 모두 가상 데이터입니다. 외부 라이브러리 없이 HTML·CSS·JavaScript 한 파일씩으로 동작하며, 팔레트 5개와 사용자 지정 색, 라이트·다크 모드를 고를 수 있습니다.


## 공용 가상 상품 (판매 수명 유형 6가지)
품의 8건은 판매 수명 유형 6가지(① 정점이 초반·이후 하락, ② 완만 상승·유지, ③ 계절성, ④ 하락 후 재상승, ⑤ 실적이 짧은 신상품, ⑥ 행사 급등)마다 1~2개씩 만든 가상 상품입니다. [상품 한 장](https://rustyhaa.github.io/product-lifecycle-demo/)·[처분 화면](https://rustyhaa.github.io/disp-lifecycle-site/)과 같은 상품이며, 데이터는 `products.js`에 있습니다. 일반 사용자 화면(`user.html`)의 사례 4개는 따로 둔 예시입니다.

## 세 화면 공통 위쪽 띠
`lifebar.js`: 세 화면(품의 추적·상품 한 장·처분) 맨 위에 같은 띠를 둡니다. 상품을 고르면 그 화면이 같은 상품으로 바뀌고, 띠의 단계를 누르면 같은 탭에서 다른 화면의 같은 상품으로 갑니다. 상품 목록은 공용 가상 데이터 생성기가 만듭니다.
