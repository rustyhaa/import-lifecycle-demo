# 수입상품 생애 추적 데모

수입상품이 물류센터에 들어온 뒤 매장으로 나가 팔리기까지를 주 단위로 따라가는 화면 데모입니다.

- 일반 사용자 화면: `index.html` (사례 4개: 계속 입고 · 빨리 소진 · 매장 체류 · 센터 정체)
- 실무자 화면: `pro.html` (가상 발주 검토 10건의 목록, 생애 차트, 비교, 경보)

화면의 상품·수치는 모두 가상 데이터입니다. 외부 라이브러리 없이 HTML·CSS·JavaScript 한 파일씩으로 동작하며, 팔레트 5개와 사용자 지정 색, 라이트·다크 모드를 고를 수 있습니다.
